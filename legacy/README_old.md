# Book-Lens-
A project that helps readers find new books by exploring what connects the books they already love.

About
BookLens is a book discovery project I'm building to explore the connections between books, authors, and literary themes.

The idea is to make discovering new books more interesting by looking beyond genres and popular recommendations.
Planned Features
- Search and explore books.
- Create a personal book collection.
- Discover connections between books, authors, and themes.
- Get personalized book recommendations.
- Explore book relationships through an interactive network.
- View insights into reading preferences.
Technologies
- Python
- Flask
- SQLite
- HTML, CSS, JavaScript
- Cytoscape.js
Project Status
Currently in development.
Goal
To build a useful book discovery platform while exploring data structures, algorithms, graph theory, and recommendation systems.
